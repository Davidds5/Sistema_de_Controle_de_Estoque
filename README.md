<h1>📦 Sistema de Estoque — Java POO + Exceções</h1>

<p>
Sistema criado para estudar Programação Orientada a Objetos, tratamento de exceções,
Stream API e boas práticas em Java.  
Um projeto simples e funcional, com operações reais de estoque.
</p>

<h2>🚀 Tecnologias Utilizadas</h2>

<ul>
  <li>Java 17+</li>
  <li>Programação Orientada a Objetos (POO)</li>
  <li>Exceções Personalizadas</li>
  <li>Stream API</li>
  <li>List & Collections</li>
  <li>Scanner (entrada de usuário)</li>
</ul>

<hr>

<h2>🧠 Conceitos Aplicados</h2>

<ul>
  <li>Classes, Objetos e Construtores</li>
  <li>Encapsulamento e validações</li>
  <li>Streams para busca e cálculo</li>
  <li>Manipulação de listas com ArrayList</li>
  <li>Tratamento de erros com try/catch</li>
  <li><strong>Exceções personalizadas</strong></li>
  <li>Logs de erros gravados em arquivo</li>
  <li>Organização profissional por pacotes</li>
</ul>

<h2>📁 Estrutura do Projeto</h2>

<pre>
br/com/estoque
 ├── Domain
 │     └── Produto.java
 ├── Exceptions
 │     ├── ProdutoNaoEncontrado.java
 │     └── QuantidadeInvalida.java
 ├── Service
 │     └── EstoqueServico.java
 ├── Util
 │     └── LoggerUtil.java
 └── Main
       └── SistemaDeEstoque.java
</pre>

<hr>

<h2>📝 Funcionalidades</h2>

<ul>
  <li>✔ Cadastrar produtos</li>
  <li>✔ Entrada de estoque</li>
  <li>✔ Saída de estoque com verificação</li>
  <li>✔ Listagem de produtos cadastrados</li>
  <li>✔ Cálculo do valor total em estoque</li>
  <li>✔ Tratamento completo de exceções</li>
  <li>✔ Registro de erros em arquivo (logs)</li>
</ul>

<h2>🛠 Como Executar</h2>

<ol>
  <li>Instale o Java 17 ou superior</li>
  <li>Clone o repositório:
    <pre>git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git</pre>
  </li>
  <li>Compile:
    <pre>javac br/com/estoque/Main/SistemaDeEstoque.java</pre>
